Key Projects 02

>>>농기계 매뉴얼 VLM 학습데이터 분류 기준 재정립

고령층 농기계 매뉴얼 VLM 학습데이터의 분류 일관성 이슈를 해결하기 위해 3,000개 QA를 전수 검토하여 추론·추출 분류 기준 재정립

3,000전수 검토한 QA 데이터

Architecture

전체적인 아키텍처

3,000개 QA를 두 유형(추론·추출)으로 분류하는 과정에서 발견된 경계 모호 문제를 기준 재정립으로 되돌려 처리.

Problem

문제 원인

  • 추론형과 추출형의 구분 기준이 명확하지 않았음
  • 같은 데이터가 작업자에 따라 다르게 분류될 수 있었음
  • 답변에 필요한 정보가 여러 페이지에 흩어져 있는 사례가 존재했음
  • 초기 기준에 경계 사례가 충분히 정의되지 않아 데이터·리포트 일관성이 떨어질 수 있었음

Process

해결 과정

  • 기존 3,000개 데이터를 다시 확인하고 분류가 어려운 사례를 별도로 정리
  • 선임 연구원과 경계 사례를 함께 검토
  • 추론형과 추출형의 새로운 판단 기준을 작성
  • 변경된 기준으로 전체 데이터를 재분류
  • 테스트
    • 새 기준을 기존 데이터에 동일하게 적용해 모호한 사례가 다시 분류되는지 확인
    • 작업자 간 판단 차이가 나는 사례를 재검토하고 최종 데이터를 전수 확인

Result

결과

  • 50개 PDF에서 3,000개 QA 데이터를 구축
  • 모호했던 두 유형의 분류 기준을 재정립
  • 변경된 기준에 따라 전체 데이터를 재작업
  • 작업 결과를 동일한 기준으로 관리할 수 있는 형태로 정리
