Key Projects 01

>>>한국어 QA RAG 문서 배치 최적화

검색 문서 수와 정답 위치에 따른 한국어 QA RAG의 성능 편차를 줄이기 위해 문서 배치 조건을 비교 실험하여 가장 안정적인 설정(K=8) 도출

K=8가장 안정적인 훈련 문서 수

진행 과정

  • 문서 수 K를 여러 조건으로 나눠 실험하고 정확도를 비교
  • Golden Document의 위치를 바꿔가며 정확도 변화를 측정
  • 입력 문서의 시작과 끝에 경계 토큰([DOC_N])을 추가해 문서 단위를 구분

성과

  • 검색 문서가 4개에서 20개로 늘수록 정확도 하락을 확인
  • 훈련 문서 수 K=8 조건이 전체 구간에서 가장 안정적
  • 7B 모델이 1.5B보다 문서 위치 변화에 덜 민감
  • 문서를 많이 넣기보다 적절한 수와 순서를 정하는 것이 중요하다는 운영 기준을 도출

Key Projects 03

>>>Reviewer-RAG 검색 검증 파이프라인

RAG 검색 결과에 섞이는 무관 문서로 인한 답변 오류를 줄이기 위해 약 8,000개 문장 벡터 DB와 Reviewer 검증 단계를 구축하여 정확도 약 3% 개선

+3%기존 RAG 대비 정확도

진행 과정

  • 약 8,000개 문장을 sentence chunk로 분리하고 임베딩으로 변환
  • PostgreSQL + pgvector 기반 검색 DB를 구축
  • 검색된 문서를 Reviewer가 먼저 확인하도록 파이프라인에 검증 단계를 추가

성과

  • 약 8,000개 문장을 검색 가능한 형태로 구축
  • 데이터 검색과 답변 생성 사이에 검증 단계를 추가
  • 기존 RAG 대비 정확도 약 3% 향상
  • 이름은 유사하지만 주장과 무관한 문서를 일부 제거
